## [Unreleased]

First public release, to be tagged `v0.1.0` when the repository goes public.

### Added

- `handoff-guard.mjs`: one Node script, built-ins only, that saves each reply's recap as a hand-off note,
  shows the notes to the next session, tells a handed-off session to stop, and checks a "100% done" claim
  against git. Serves Claude Code, OpenAI Codex CLI and xAI Grok Build.
- An installer per tool (`install-claude.mjs`, `install-codex.mjs`, `install-grok.mjs`), dry-run by default,
  with a backup of every file it changes.
- A guide per tool: `BUILD-YOUR-OWN-CHAT-HANDOFF.md` (Claude Code, the full design), `BUILD-YOUR-OWN-CODEX-HANDOFF.md`
  and `BUILD-YOUR-OWN-GROK-HANDOFF.md`.
- 75 tests and a 103-mutation check (`npm test`, `npm run mutate`).
- A check, `no saved pages`, that refuses any web page, office document or link to a hosted Claude page in every
  commit of a pull request and in the history of `main`. Its one exception, a helper the diagram build opens, is
  pinned by content. It runs from `main`'s copy, so a pull request cannot switch it off by editing it. Its own
  tests and mutations run with `npm run fence`.
- The Southlodge sign-off: each snippet ends the recap block with `🛡 Southlodge.ai`, pushed right to column 80
  (76 in the Codex snippet, because the Codex panel holds just under 80 columns when wrap is on). The script
  strips the mark, and the spaces before it, before it reads the block, so the mark is never saved as part of a
  step, the next step, the ETA or the title. "The sign-off" in the README says how to leave it out.
- Continuous integration on Ubuntu and Windows for Node 20, 22 and 24, with the mutation run on Ubuntu.
- Five system diagrams in `assets/diagrams/`, each in a light and a dark version that GitHub picks to match the
  reader's theme, generated by Node scripts in `assets/diagrams/src/`. The build checks layout, contrast (WCAG AA),
  consistency across the three tools and the README alt text; a 25-case mutation run proves those checks fail when
  they should, and CI fails if the committed SVGs differ from a fresh build.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, issue and pull-request templates, and Dependabot
  updates for the pinned GitHub Actions.

### Fixed

- Grok: when several tool calls finished at once on Windows, the hand-off menu could arrive twice. The marker
  was claimed by renaming it, and two overlapping renames of the same file can both succeed on Windows. It is
  now claimed by creating a `.claim` lock with an exclusive create; a lock left by a call that died clears
  after 30 seconds.
